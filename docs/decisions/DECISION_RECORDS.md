## 保留经验，不继承个人授权

历史上有操作者接受近音关键词、模型烧字、已生成视频不再返工、仅修未生成参考图等例外。
这些是“应记录的裁决类别”，不是允许任何第三方无条件跳过 QA 的许可。
语速增加 20%、某轮额度提高或消费重新计算，也必须在私有项目中说明范围；预算不能从聊天猜，历史账单不能清除。

自动发布、下一集自动启动、浏览器回退和插件付费影子授权彼此独立。
新的操作者需作自己的选择；本知识工具不会修改现有策略文件，也不会导入真实集数、预算、remote ID 或永久私密列表。

## 新增/覆盖规则流程

新增稳定 ID → 写失败原因与来源范围 → 标注实现状态 → 关联代码与测试 → 运行链接/回归检查 → 代码审查 → Release。
覆盖旧规则时保留 supersession 说明；没有端到端证据不能把 GUIDANCE_ONLY 改写成生产 PASS。
