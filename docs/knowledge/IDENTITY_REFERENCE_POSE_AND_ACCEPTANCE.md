# 人物参考角度、传输顺序与生成后验收

## 已证实的工程缺口

- 素材库存在已批准的三分之四视图，但关键帧编译只选择正脸，未检查低头书写等姿态的参考覆盖。
- 空间解析先后被混同为供应商图片数组顺序，人物头像没有按既有经验放在前面。
- 扁平参考图加文字标签是软条件，不是供应商原生身份硬锁。
- 单次低分不能证明换人，亦不能仅以侧脸为由宣布一致性通过。

以上是输入与实现缺口，不是对每次生成偏差的唯一因果证明。

## 实际执行

`image_model_adapter.compile_labeled_flat_identity_transport` 将人物参考置前，保留全部空间参考，按去重后的真实数组同步重编号提示词。新合同声明 IDENTITY_FIRST_V1，提交门复核该顺序；旧合同不因此失效。

`identity_pose_reference.supplement_pose_references` 已接入关键帧编译入口：从对应人物已 LOCKED、QA PASS 的素材中选择已有角度参考，记录文件及 SHA；不跨人物借图、不自动生成参考、不删除地图或改变机位。侧面图仅提供额外几何信息，不冒充精确低头姿态证明。

当前姿态发现采用保守词表与逐人物分句，不是完整语义理解。未识别的姿态仍需生成前人工提示词审核。无合格角度图或参考数量不足时记录 ADVISORY 缺口，不能伪造覆盖通过或自动付费补图。现有文件/SHA/角色冲突强门继续有效。

## 生成后裁决与重做边界

明显人物或场景不一致仍应报告；仅侧脸、光照、表情、较小脸部引起的相似度波动不单独触发付费重做。非明显差异记录 ADVISORY；没有执行的检查记录 NOT_VERIFIED。

每次失败先记录事实、排除项、原因假设和针对性修改，再决定是否重试。不能将换版本号、追加“不要换脸”当成原因分析。

用户明确接受的素材须绑定 exact SHA，保留原测量和裁决，不伪造评分或抹掉原报告。授权接受外观差异不豁免损坏、解码错误等独立技术门；不自动重发已完成任务。

## 回归测试

`tools/tests/test_identity_pose_reference.py` 与 `test_flat_reference_transport_indices.py` 覆盖参考选择、同人补充视角、真实数组编号、地图保留、未批准素材、容量限制与禁止自动付费补图。
