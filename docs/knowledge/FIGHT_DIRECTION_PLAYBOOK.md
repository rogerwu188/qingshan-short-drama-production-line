## 一、E14/E15 为什么打成了"静态 PPT"

编剧写的攻防链本身是完整的（出招、对方回应、接触、受力、新位置），但在下游被一层层压平：

1. 每次交手都夹在一句战术台词中间（「力沉，我让开」「压下去」「再进半步」）。分组把 1.5–2.5 秒的打斗镜和相邻台词镜并成一个 4 秒单元，单元里有台词，K148 就把整个单元锁成三脚架机位，编剧写的横移、推近被改成「固定机位」。
2. 打斗场景里，战斗镜头的时长不到一半，剩下的都是中近景说话。
3. 模板给每个战斗节拍补上「随后保持 / 并保持 / settles」，模型被告诉了好几次"停住"。
4. 为了让人脸识别锁住身份，站位写成「两人都侧身相对、脸都转向镜头」，成片就是两个对手并肩朝镜头站着。
5. 对手的长刀没有登记道具卡，铁矛只是声明、没出卡，模型每个单元都重新画一遍兵器，弯背大刀会在单元中途变成直剑。
6. 没有门禁检查"打斗有没有真打起来"，镜头运动门禁反而奖励锁机位。

## 三、每个交手节拍的写法

一拍 = 起势 → 接触或明确闪避 → 受力反馈 → 新位置。不要写"无接触的走位拍"单独成拍，走位并进下一个接触拍的起势里。`contact_time_seconds` 落在节拍的 25%–75% 之间。结束状态写"移到哪里"，不写"停住 / 保持"。

一场打斗至少几个回合，攻守至少换一次手（`COMBAT_EXCHANGE_V1`，见 `COMBAT_EXCHANGE_DESIGN.md`）。

## 四、成片验收（S6 后）

`major_event_presence` 对 COMBAT 节拍只在以下四条全部成立时判 PASS：

1. 接触（或闪避）在画面上看得见；
2. 接触之后身体继续动到新位置，不在原地摆姿势超过约 1 秒；
3. 双方是对手站位，不是并肩朝镜头；
4. 每件兵器整段只有一种形状。

E15 重投的验收样本：VU-021、VU-027 合格；VU-020 接触后约 4.5 秒并肩朝镜头静止，不合格；VU-019 长刀中途变成直剑，不合格。

## 四·二、E15 重投第二轮的两条经验（Roger 2026-11-07）

1. **「锁刀 / 咬住 / 顶住 / 僵持」类拍子必须带位移，单次接触不超过 0.6 s。** VU-020 第二拍写成「铁矛贴在刀面上横着顶住、震开刀势、两件兵器咬在一起」，成片 2.0–4.0 s 两人原地不动（`combat_execution_check` 最长静止 2.0 s，上一版 2.25 s）。改法：刀与矛只接触一下（≤0.6 s），随即写位移——谁把什么沿哪个方向推开多远、对方的手臂与上身被带向画面哪一侧、跟进的脚移动多少；每一句都写方向和距离，不写「顶住」「咬住」「僵持」。
2. **上一单元的尾帧如果和本单元新的起始关键帧的场景或人物站位冲突，就不挂这张尾帧。** VU-019 挂了 VU-018 的尾帧（傅恩涛单人正面举刀、另一处院子）作 PREVIOUS_REAL_TAIL_STATE_AUTHORITY，新旧两版成片都在半途切到了这张画面，兵器也随之变成直剑。起始状态已由新关键帧（两人对峙）定好时，用 `nalu_pipeline.py start-frame-decision` 让单元开在自己的关键帧上；引擎若要求同场景必挂尾帧，记一条例外订单（「尾帧与新起始关键帧冲突」）。附带：道具参考卡必须是整件道具、纯色背景（大刀只截刀尖的卡，模型推不出整把刀的形状）。
