# 打斗设计：回合制模板（COMBAT_EXCHANGE_V1）

Roger 2026-11-05：「打斗至少要有几个回合才有感觉，没有你来我往的打斗场面」。
E14 的三场打斗都是一方出一次手、对方只是滑开或倒下；引擎当时也不允许别的写法
（`COMBAT_EXCHANGE` 限 2 次接触，格挡+命中就已经占满）。本文是修复后的写法。

## 一、基本单位：一个回合（exchange）

一个回合 = 四拍，缺任何一拍都不成立：

| 拍 | 内容 | 反例 |
|---|---|---|
| ① 出手 | 主动方的完整发力链：脚 → 胯 → 肩肘 → 腕 → 刃/拳，写明距离与线路 | 只写「秦铭一刀劈下」 |
| ② 应手 | 对方**具名**的应对：格挡 / 架开 / 侧闪 / 夹刃 / 卸力 / 反手还击 | 对方只是「退开」「倒下」 |
| ③ 受力 | 力在双方身上的可见证据：衣料、雪面、脚下、重心、呼吸 | 「两人分开」 |
| ④ 新站位 | 各自落到的可持续位置，下一回合从这里起手 | 回到原来的对峙姿势 |

**主动性必须易手。** 一个单元里，至少有一个回合由对方发起，或用一次明确反击把主动权抢过去。
只有一方一直在打，那不是打斗，是演示。

**相邻回合不能重复**同一招对同一应手。第二回合必须回答第一回合的结果：换线路、换高度、换距离、换节奏。

## 二、整场戏的弧线

一场打斗至少 **3 个回合**（推荐 3–5），按四段走：

1. **试探**：拉近、互相试招，观众看懂两边的风格与武器
2. **升级**：一方真的打中/压住，另一方的应对开始变粗、变急
3. **转折**：处于下风的一方换条件——反击、换手、借地形、以伤换位
4. **定局**：最后一个回合一击定胜负；结果写**身体状态**，不写谁厉害

弧线可以横跨同一场的多个单元；单个单元内至少要有一个完整回合。

## 三、拆到单元里（4–8 秒一镜给不了太多）

- 一个 4–8 秒单元最多容纳 **2 个干净回合**；3 个回合的戏要拆到至少 2 个单元。
- 每个单元**结尾必须落在新站位**，下一个单元从那里接（D-68）。
- 单元最后不许「回到起点再结束」。
- 摄影：一个单元只走一条主运动（横移 / 环绕 / 后拉 / 固定）；不要叠推拉+甩镜+环绕+手持抖。
- 每个可读回合都要看见双方全身，或至少双方的双手与兵器；不许把胜负交给画外。

## 四、写法规则

- **写可见的几何，不写形容词**：「从三步压到一臂距离，右肩带着前臂撞进对方左肋」；
  「他打了一拳」不算描述。
- **重复名词，不用代词**：两人同框时写「巡山者的刀」「秦铭的右膝」，不写「他」。
- **不写输赢、不写强弱、不写意义**，只写看得见的结果。
- **禁用词**：持续、保持、连续（会把回合写成摆拍，`COMBAT_EXTEND_WORD_FORBIDDEN` 已拦）。

## 五、一个写好的例子（短刀对短刀，3 回合拆进 2 个单元）

**单元 A（6 s，2 回合）**
- 回合 1（0–2.6 s）：巡山者右脚蹬雪、重心压前，长刀从右肩斜劈下来，线路指向秦铭左肩（①）；
  秦铭不退，右前臂横举刀身中段迎上去格开，刀身相磕的一声在雪地里很干（②）；
  两把刀各自被弹开半尺，巡山者前脚滑出半步、上身被迫后仰（③）；两人各退半步，刀尖重新朝下（④）。
- 回合 2（2.6–5.2 s）：**主动权易手**——秦铭借对方后仰的一瞬，前脚抢进，反手刀自下往上撩向对方持刀的手腕（①）；
  巡山者收刀下压想挡住，慢了半拍，刀背擦过护腕（②）；他的护腕上翻起一道浅痕，重心被抬起来（③）；
  他连退两步、脚跟踩进深雪，秦铭停在半步外，刀尖仍指着他的手（④）。
- 结尾：秦铭刀尖指着对方手腕，对方脚跟陷进深雪（下一单元从这里起手）。

**单元 B（5 s，1 回合 + 定局）**
- 回合 3（0–3.2 s）：巡山者急了，不再算计，抡圆了长刀横扫，线路压得很低（①）；
  秦铭没有格挡，整个人贴地矮下去从刀下钻过，同时把刀送进对方扫击的空档（②）；
  刀锋擦过他的发髻，而他的刀锋压上对方肋下；对方的扫击停在半空、身体一软（③）；
  巡山者跪进雪里，长刀脱手插进雪面；秦铭单膝落地、刀横在身前（④）。
- 结尾：一人跪地、刀插雪中，一人单膝落地持刀——不可逆的结果。

对照 E14 的实际写法：`秦铭一脚踩爆雪面冲上去，那人往旁边一扑，刀光掠过，那人扑进雪堆`。
这四个动作只有一个接触、对方没有任何一次出手，所以看起来「太简单」。

## 六、机器怎么拦

- `tools/combat_exchange_gate.py`（`COMBAT_EXCHANGE_V1`，E15 起默认生效）：
  每拍必须有 `defender_answer`、有受力、有新站位；主动性必须易手；相邻不得重复；整场至少 3 回合。
- `tools/grouped_performance_contract.py`：战斗拍必须带
  `combat_choreography.exchange{initiator, attack, defender_answer, new_position}`。
- 这些都在编译期（付费前）判定，失败直接 BLOCKED，不花钱、不需要重投。
