## 一、位置(流水线次序)
```
剧本(剧情密度门+议会) → 生成 → 剪辑(Narrative Gate) → 技术审核(CI机器门)
   → ★模拟观众审片门(本规范,<3 打回重剪) → 监制 aHash 独立复检(兜底) → 发行 → 删旧
```
- **前置**:必须技术审核已 PASS(不黑帧/不断句/音画同步等)才进本门——本门只管"好不好看",不重复查技术安全。
- **强制**:本门是**发行前必过硬门**,由 codex 执行;打分 ≥3 才可进入发行;<3 自动打回重剪并附问题清单。

## 二、怎么"模拟观众"看
codex 对即将发行成片:①**完整 1× 看一遍**(不快进);②**做一次静音观看**(竖屏观众常静音,验证无字幕/纯画面能不能看懂);③**做一次开声观看**;④以"平台上划到这条、随时会划走的普通付费短剧观众"心态判,不以制作者视角自我宽容。

## 三、打分维度(每项 1–5,综合分为整体观感非简单均值)
| 维度 | 问的问题(普通观众) | 权重 |
|---|---|---|
| **① 故事性/悬念** | 看得懂在讲什么吗?想不想知道接下来?钩子立不立得住? | 核心·重 |
| **② 续看意愿** | 看完会不会点下一集? | 核心·重 |
| **③ 节奏/观看体验** | 拖不拖?闷不闷?有没有反复看同一个东西的重复感?比实际时长感觉更长? | 核心·重 |
| ④ 开场钩子 | 前 3 秒抓不抓人? | 中 |
| ⑤ 人物与易懂度 | 分得清谁是谁吗?知道谁在说话、在干嘛吗? | 中 |
| ⑥ 画面 | 场景是否千篇一律?有没有变化与唯美?有没有穿帮(如角色错色)? | 中 |
| ⑦ 真实感(反AI感) | 脸型/妆发是否漂移?动作情绪跟台词匹配吗?道具是否前后一致? | 中 |
| ⑧ 完整可看 | 有没有字幕?静音能不能懂?音画同步? | 中(硬项) |

## 四、判定
- **综合分**:以①②③为核心的整体观众观感(5 分制),不是八项算术平均。
- **≥3.0**:通过,进监制 aHash 复检→发行。
- **<3.0**:**打回重剪**,输出**问题清单+重剪建议**(逐 beat/逐镜:哪里重复、哪里没字幕、哪里穿帮、哪里节奏拖、哪句该做爆点),供剪辑器精确修复,不重生成整场。
- **硬项一票否决(即使综合≥3 也打回)**:无烧录字幕 / 角色身份错色穿帮(如乌云非黑)/ 同一语义对象重复占比 >15% / 开场 3 秒无钩子。这几项属"观众可感的毁片级",单独出现即打回。

## 五、防刷分(核心:分不能是拍脑袋的数字)
观众分必须**有证据支撑**,与 Narrative Gate 客观指标交叉,不得空给高分:
- 打分报告须附:抽帧网格(看场景多样/穿帮)、ASR 转录(看故事可懂/字幕依赖)、同语义组占比、场景轮换表、字幕在位与否。
- 与剪辑 Narrative Gate 指标一致性校验:若 semantic_group 盒子类 >15% 或 NARRATIVE_STAGNATION 存在,则③⑥不得高于 2。
- **监制 aHash/coverage 独立复检为兜底**:codex 自评可能偏宽,监制在发行前独立再验一次语义重复/字幕/身份色;两侧从严者胜。
- 15 分钟无人工响应→按 `ROGER-20260717-HUMAN-GATE-15MIN` 机器自评自决,但硬项一票否决仍生效。
