## 一、为什么 v1 没起作用（先认这个，否则 v2 会重蹈）

1. **固定 5 场模板**：E40–E45 每集恰好 5 场、每场 26–40s。E40 全 5 场在王府花厅，E43 全 5 场在废窑仓——
   **一个房间演满一集**，是结构上最慢的排法。场数应由剧情定，现在由模板定。
2. **密度门只查数字**：`SCRIPT-US-DRAMA-EVENT-DENSITY` 的 `scope="R-49_NUMERIC_ONLY"`。
   E38 v2 自报 11 事件/分钟（门的目标上限 6）照样过审，观感依旧慢——因为"事件"由写手自己定义、自己计数。
3. 故：**把 4-6 提到 8-10 是错解**。数字可灌水，结构不能。v2 只加不可自报、可机器核的结构指标。

## 二、四条结构硬指标（缺一即 REVISE）

### ① 场数由剧情决定，禁固定
- 每集 **8–12 场**（现为固定 5），**禁止任何集恰好等于模板值**；连续 3 集场数相同需写明剧情依据。
- **单场硬上限 22s**（现为 26–40s）。超 22s 必须拆场或砍内容，**不得靠加台词填满**。
- 单场下限 6s——允许短插入场（一句话、一个动作、一个反应即成场）。

### ② 空间与时间必须动
- 每集 **≥4 个不同 location**，**禁止全集发生在同一地点**（E40/E43 型排法作废）。
- 每集 **≥1 次时间跳跃**（夜→晨、当日→次日等），禁全集压在同一时段。
- 同一 location 连续场次 **≤2**，第 3 场必须换地方或跳时间。

### ③ 交叉剪辑：至少两条线并行
- 每集 **≥2 条同时推进的线**（主角线 + 对手线/受害者线/第三方线）。
- 全集 **≥3 次跨线切换**，且切换点必须落在**悬置处**（对方正要说出口 / 手正伸向门 / 刀正落下），禁在事情说完后才切。
- **这是"快"的最大来源，也是成本最低的来源**——见第四节。

### ④ 每场必须有转折与钩子
- 每场进场晚出场早：**开场首 3s 内必须已在事件中**（禁"走进来—坐下—开口"），末尾必须留 button。
- 每场结束时，下列至少一项发生改变：**谁掌握主动 / 谁知道了什么 / 谁失去了什么 / 谁被迫做了选择**。
- 无变化的场 = 删除或并入相邻场。

## 三、事件定义收紧（反 Goodhart，取代自报计数）

**可计数的事件**——观众看完能复述"谁做了什么 → 导致什么变了"：
- 有人做了**不可撤销**的事（下毒、烧毁、杀人、签字、交出、逃走）
- **权力或关系**改变（结盟、背叛、要挟成立、被迫服从）
- 出现**新的物理事实**（尸体、账册、密道、伤口、追兵到门口）
- 有人**得到或失去**某物/某人
- 有人**被迫在两难中选择**

**不可计数**（v1 时期被大量计入，是虚高主因）：
- 看见 / 听见 / 意识到 / 想起 / 确认 / 判断 / 下决心（无外部动作）
- 解释既有信息、复述观众已知、二次说明画面已演的内容
- 情绪反应本身（除非导致上列某项改变）

**复核方式**：**不采信写手自报**。监制独立按上表重数，与自报差异 >30% 即 REVISE。

## 四、成本约束（本条防止"加场=加钱"）

场数翻倍**不等于**地点翻倍。达标的正确做法：

- **优先用交叉剪辑造场**：在已建立的 2–3 个地点之间来回切，每次切换即成新场，**零新增资产**。
- 复用本集已有 location 的不同角落/景别作为短插入场（≤10s）。
- **新增 location 每集 ≤2 个**，超出需在 manifest 写明理由。
- 短插入场优先用**已准入素材的反应镜/空间镜**，不为凑场数新生成。

**换算**：8–12 场里，约 5–7 场是实拍主场，3–5 场是交叉切回或短插入。资产增量控制在 +20% 以内。
