# 生产线网络武侠打斗镜头库集成报告 V1

日期：2026-09-01
状态：已实现，待公共发布与 E51 激活

## 1. 结论

`WEB_WUXIA_COMBAT_AI_PROMPT_LIBRARY.md` 已被转译为 34 个结构化 profile。原文只作为摄影与动作表达参考，未被当作剧情、来源文本、对白、声音、特效或胜负权威。

新增层位于共享 Action-IR 之后、SD2/H3 模型渲染之前：

1. Canonical/导演稿决定人物、事件、地图、天气、轴线、镜头类型、动作、接触、伤势和结果。
2. Action-IR 固化起态、力源、动作、接触/闪避/威胁临界点、主反馈和不可逆终态。
3. 武侠 profile 选择器只根据已存在的武器、人数、交互、环境与授权信号选择表达原型。
4. SD2 输出精简中文模块；H3 输出等价英文模块；两者共享同一 profile receipt。

## 3. 不会被改变的结构化权威

选择器禁止改写以下内容：地图、天气、时段、光向、轴线、景别、导演运镜、身份、服装、道具主人、左右手、对白、声线、Action-IR、接触类型、伤势、胜负、剧情结果。

profile 也不得新增：未授权招式、命中、破坏、群众、内力、剑气、法术、台词、音乐或音效。`AUTHORIZED_FX` 与 `STYLE` 只能由结构化授权显式选择，永不自动推断。

## 4. 选择结构

每个打斗单元最多绑定：

- 1 个 `PRIMARY_ACTION`
- 1 个 `ENVIRONMENT`
- 1 个显式授权的 `AUTHORIZED_FX`
- 1 个显式授权的 `STYLE`

选择 receipt 固化 profile id、库版本与 SHA、选择理由、被拒候选及拒绝原因。相同输入必得相同结果。

## 5. QA 边界

新增 profile 的六项检查均属于付费提交前 QA：

- 身份与武器归属唯一
- 起态—力源—交互—反馈—终态完整
- 只选一个主环境反馈
- 摄影能读清动作且不越轴
- 终态可观察且不可逆
- 无来源/IP/对白/未绑定声音污染

生成后仍遵守现行范围：只做技术检查与基本情节检查，不增加动作合理性、动作细节或动态媒体审美门，不因此浪费重生成预算。

## 6. E51 使用要求

E51 保持 SD2 标准版、720p、9:16、完整地图模式。语义视频分组时，每个 combat 单元必须写入 `wuxia_combat_profile_required=true` 和显式 `wuxia_combat_profile_signals`；未解析主动作 profile 不允许进入付费提交。雨只能来自既有天气合同，并且在打斗 profile 中最多作为一个主介质反馈，不得由镜头库擅自增雨。
