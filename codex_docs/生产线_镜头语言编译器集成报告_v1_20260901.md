# 生产线镜头语言编译器集成报告 v1

日期：2026-09-01
状态：IMPLEMENTED_AND_TESTED

## 1. 目标

把 `TASK2_CAMERA_LANGUAGE_COMPILER_INTEGRATION.md` 与
`DOUYIN_AI_MANHUA_SHOT_PROMPT_STANDARD.md` 中可验证的摄影语言，转换为结构化、确定、可审计的生产线能力，而不是把参考文档全文堆进视频提示词。

本次集成不修改剧情、地图、天气、镜头类型、轴线、人物站位、动作结果或模型选择。

## 2. 新增层

共享执行计划在 Action-IR 完成后、SD2/H3 各自渲染前运行
`camera_language_selector`：

1. 读取导演已定的 `camera_plan`；
2. 按视频单元类型确定唯一 profile；
3. HYBRID 模式仅补充焦段数值、动作清晰度与景深意图；
4. SD2 渲染器输出简短中文摄影句；H3 渲染器输出等价英文摄影句；
5. 选择结果进入共享语义 SHA 与 lineage receipt。

## 3. 不可改写字段

- `shot_scale`
- `camera_height`
- `camera_side`
- `axis_relation`
- `motion_family`
- `motion_direction`
- `start_framing`
- `end_framing`
- `motivation`
- `lens_intent`

任何选择器导致上述字段变化都会 fail closed。

## 4. Profile

- `CAM-DIALOGUE-CONTROLLED-V1`：50mm，正常实速，受控主体分离；不得虚化对手或关键道具。
- `CAM-ATMOSPHERE-SPATIAL-V1`：28mm，正常实速，较深空间可读性。
- `CAM-PHYSICAL-ACTION-CLEAR-V1`：35mm，动作方向清晰，中等景深。
- `CAM-COMBAT-IMPULSE-CLEAR-V1`：35mm，接触清晰，较深景深。
- `CAM-COMBAT-EXCHANGE-CLEAR-V1`：28mm，仅快速肢体允许顺方向轻微动态模糊，较深景深。

复杂打斗的轴线、构图、运镜和动作结果仍由导演稿与 Action-IR 手工锁定；profile 不替代动作设计。

## 5. 特效安全

氛围效果和视觉特效默认不存在。只有输入中的
`camera_style_authorizations.atmosphere_intent` 或
`camera_style_authorizations.effect_intent` 明确授权时，选择器才会透传对应字段。

因此，参考文档中的雾、光束、震动、慢动作等示例不会自行污染既定天气或镜头合同。

## 6. 模型边界

共享层只输出模型中立的枚举与数值。SD2 与 H3 保持各自独立提示词语法：

- SD2：简短中文摄影描述；
- H3：英文机器提示词，中文只允许存在于对白标签内。

两种模型对同一视频单元必须具有相同的 `execution_semantics_sha256`。

## 7. 验证

已覆盖：

- 选择确定性；
- LOCKED 模式不补字段；
- HYBRID 模式不改导演字段；
- 未授权特效不进入计划；
- SD2/H3 共享语义 SHA；
- 摄影字段进入两种模型各自提示词；
- 原镜头方向重复门与通用措辞禁令保持有效。

仓库全量测试发现的首个错误是既存可选依赖 `agentcut` 未安装，与本次改动无关；本次相关 74 项回归全部通过。

## 8. E51 激活方式

E51 使用 SD2 标准版、720p、9:16、完整地图模式。全部视频单元在付费提交前必须：

1. 通过地图、天气、身份、道具、声音与 Action-IR 结构门；
2. 通过 camera-language HYBRID 选择和审计；
3. 生成模型专属提示词；
4. 通过预提交语义覆盖门；
5. 才允许写入付费事务并提交。

生成后 QA 仍只做技术检查与基本情节检查，不恢复动作细节类动态媒体审查。
