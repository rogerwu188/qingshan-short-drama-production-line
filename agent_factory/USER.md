# AI短剧工厂 Agent 用户说明 v0.4

你正在使用的是一个“AI短剧工厂”agent。它的目标是把网文、原创故事、人物参考图和运营目标，转化为可连载、可发行、可持续迭代的真人短剧生产线。

## 你需要提供

- 原著文本、小说链接或剧情大纲。
- 希望改编的题材、时代、风格、受众和发行平台。
- 主角、重要配角、宠物、道具、场景的参考图或文字设定。
- 平台账号状态、可用视频模型、预算和是否允许自动发行。
- 对节奏、尺度、字幕、片头片尾、品牌露出的特殊要求。
- 已出现角色、配角、宠物、关键道具和场景的上一集截图或参考图；没有参考图时，Agent 会先建库再生产。

## Agent 会交付

- 分卷/分季改编规划。
- 每集 3 分钟左右的竖屏短剧剧本。
- 角色库、场景库、道具库、声音/音乐库、画风库。
- 每集任务卡：创作、生成、QA、返修、导出、发行、复盘。
- AI Director / Giggle / StoryClaw 等平台的可执行生产提示词。
- 每集成片 QA：人物一致、场景一致、道具一致、声音一致、字幕、片头、片尾、节奏和转场。
- 最终发行 MP4 声音 QA：确认中文对白、声线一致、无英文污染、无串音和无对白空段。
- 抖音、YouTube Shorts 等发行文案和发布检查。
- 失败复盘和工作流自动升级。
- 返修链路：坏镜头会回到素材/故事板/视频 prompt 的正确源头处理，而不是绕过工作流临时拼凑。
- 双监制交付：可把剧本、成片、QA 包交给 Claude 或 StoryClaw 云端监制异步复核；报告会写回生产信箱，但不会让生产线因为等待回复停工。
- 可迁移安装：Agent 会维护 `agent_factory/`、`bootstrap/`、工具注册表和便携包，便于未来迁移到 StoryClaw 或异地机器继续生产。
- 成熟工具链：已内置 OCR、ffmpeg、Giggle API、CI、亮度审计、资产继承、连续性审片、StoryClaw 文件桥等固定能力。

## 质量标准

- 每 5-8 秒必须出现新信息、新动作、新冲突、新证据或反转。
- 一切拖剧情的慢动作、脸部停留、心理气氛都要压缩。
- 相邻镜头必须有声桥、动作接、方向接、道具接、空间接或因果接。
- 主角、配角、宠物、场景、道具、声音跨集必须一致。
- 背景音乐不能全程铺满，台词、环境声、拟音和沉默同样重要；有字幕但无对白语音不算合格短剧成片。
- 每集必须有爽点、钩子和下一集牵引。
- 台词必须在镜头内说完；话没说完、被切断、下一镜接不上，视为返工。
- 视频必须是真人动作短剧镜头；静态图、故事板动效、无对白特写不能作为正式成片。
- 默认中文真人短剧不允许出现英文对白或随机欧美人物，除非剧本明确需要。
- 模型过不了时，Agent 会先改提示词，再切 Seedance / Sora2 / Veo 3.1 / Wan 2.7 / 可灵等可用模型，而不是牺牲题材。
- 正式视频 prompt 必须拆分视觉与音频：视觉只写表演、动作、镜头、灯光、场景和负向约束；正式台词、语气、声线、停顿、重读只进入音频字段，防止模型把对白画成原生字幕。
- 已出现角色/场景/道具/声音必须从资产库继承；同一角色可以换服装，但不能换脸、换身材或换声线。

## 重要限制

Agent 不能绕过登录、验证码、版权授权、平台审核、余额不足或用户明确禁止的操作。涉及删除已发布作品、公开发布、扣费异常和账号安全时，必须在行动前确认。
