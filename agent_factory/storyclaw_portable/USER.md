# 欢迎使用 NALU 短剧生产线

安装完成后，你可以用自己的故事创建一个独立的 AI 短剧项目。项目的原著、素材、成片、
账本和密钥保存在你的 StoryClaw 私有运行时，不会被打进公开仓库或 TalentHub 发布包。

## 开始时请提供

下面四种来源任选一种即可：

- 直接粘贴原著或剧情文本；
- 上传 `.txt`、Markdown 或其他受支持的文本文件；
- 提供你有权使用且可公开访问的正文网址；
- 提供原创剧情大纲，让编剧代理据此扩展。

你还可以一并上传主角剧照、人物参考图、场景图、道具图或素材目录。此时不必逐一说明图片
属于谁；代理会先完成剧本，再根据实际角色和场景自动匹配。如果没有可用主角剧照，完整
方案会明确提出 AI 生成主角身份素材并给出提示词、模型与预计成本。

剧名、时代、语言、风格、单集时长、目标集数和总预算都可以选填。没有填写时，代理会先
给出合理默认值，并把它们放进后续的统一确认方案。

示例开场：

> 请以我上传的小说建立新项目。做中文 9:16 竖屏短剧，先制作第一集；参考图都在本次上传
> 的素材中，其余设置请根据剧本提案。

或：

> 请从这个可访问的网址建立新项目：`https://example.com/story`。先完成免费剧本和预制作，
> 在任何付费生成前给我完整方案和预算。

## 接下来会发生什么

1. 代理建立项目专属的私有运行目录与系列范围，保存来源并记录 SHA-256；
2. 编剧代理生成四层剧本，运行 S1 门禁和自检；
3. S1 通过后运行 S2，提取真实角色、场景、道具和镜头需求；
4. 代理自动匹配已上传素材，并为所有缺口准备 AI 生成方案；
5. 你会收到一份包含剧本摘要、全部素材选择、生成提示词、模型、风险和预算的统一方案；
6. 你一次确认整体方案后，代理才可按有效订单与付费双锁进入 S3–S8；
7. 最终交付私有成片、QA 报告、检查点和预算/供应商对账证据。

如果网址需要登录、遇到验证码、付费墙、反爬限制或只提供摘要，代理不会绕过限制，也不会
凭空补写正文。它会请你粘贴正文、上传文件或提供获准使用的替代来源。

## 你只需要集中确认一次素材方案

代理不会逐个角色反复问“上传还是 AI 生成”。它会先根据已通过的剧本自行选择匹配结果，
再把所有选择放在同一个方案里供你确认。方案发生变化时会重新确认，防止旧授权误用于新
提示词或新素材。

付费前还需要项目负责人的有效私有订单，明确项目、集号、预算和允许的生成范围。该订单
不会进入公共包。密钥通过 StoryClaw 秘密管理配置，请不要把 API key 粘贴到聊天消息中。

## 模型与发布

默认优先使用 GPT-6 Astra，其次使用 Claude Opus 5；两者不可用时才使用 GPT-5.6 Sol。
不会使用 Kimi 或 MiniMax。生产完成后，代理不会自动上传到视频或社交平台。需要公开发布
时，请另行明确指定平台和操作范围。

StoryClaw 实机调试产生的通用修复会回灌代码仓库，经过测试、打 tag 和校验后重新打包到
TalentHub。这样后续用户安装新版即可获得修复，无需在每台设备上重复相同调试。

## 日常升级

代理每天静默检查已签名并通过 StoryClaw 实机验收的稳定版。普通引擎更新会先并行安装和
验证，只在安全停点切换；正在制作的一集始终使用启动时版本，失败时继续使用旧版。如果
更新涉及安装器、引导、依赖或运行时结构，代理会提示执行：

```bash
talenthub agent update ai-drama-factory
```

更新后会从已有检查点继续，不需要重新建立项目或重新提交已经登记的任务。
