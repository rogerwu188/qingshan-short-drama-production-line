# Portable script-council checklist

This checklist applies to every newly initialized StoryClaw series. It carries
no story, character, episode, customer, or private-runtime facts.

Before paid generation, independent script reviewers must inspect the exact
four-layer script bytes and record their identities, model ids, task ids,
verdicts, and evidence hashes. The chair may issue `PASS` only when every
required reviewer has submitted a complete response bound to the same script
SHA-256. Missing, stale, partial, or self-filled answers remain
`REVIEW_REQUIRED`; they never become an inferred pass.

Review at least source fidelity, dramatic clarity, causal continuity, visual
producibility, dialogue performance, period/world consistency, and whether the
opening and ending work for a vertical-drama audience. Any accepted exception
must use the registered line-owner order mechanism and bind the affected media
or script hash.
