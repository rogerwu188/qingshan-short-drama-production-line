## 八·补三(2026-07-24)、★继承要点：环境生命层 ambient_life（CL2X-674，每集必带·按场分级）
模型只让**被文字描述的主体**运动 → 剧本没写的背景人物一律成静态布景（满场看客/路人全冻住、只主角在动＝一眼假）。**分级填写，不是每镜都加**：**A级必须有**（人群／市集／户外／风）＝写群体动作趋势；**B级微环境**（室内有他人或风/火/水）＝烛焰摇、帘动、纸页掀、小动作；**C级刻意静**（密室独处、深夜对峙，静即是戏）＝明确写"环境静"，禁强行加动。A/B 级镜**首帧背景须处动势中**；负向词加"背景静止·人群定格·布景板·蜡像"。群戏/打斗中背景反应**逐拍升级**，禁人群列队不动。

## 八·补二(2026-07-24)、★继承要点：逐镜首帧动势 first_frame_motion_state（CL2X-670，每集必带）
每镜 `still_prompt_contract` 必填 `first_frame_motion_state`（缺=blocker）：①**首帧=动作中途的失衡瞬间**（手伸到一半／身体正在转／物件正在落下／脚正离地／衣袂正被带起）；②**首帧信息故意不全**——只给局部（手／道具特写／半张脸／被前景遮挡），真信息在镜内才揭开；③负向词加"完成态·摆拍·对称站定·看镜头·亮相·静止起手"。
**病根**：首帧若画"内容已全部就位的完成态"，视频模型只能从完成态往后演 → 每镜"先亮相 0.3-1s 再动" → 整片话剧感／PPT 翻页感，且与"进晚出早"剪辑纪律直接对冲（素材前半截就是亮相，剪辑无从进晚）。Roger 2026-07-24 观看 E35 亲诊；E35 不重剪，E36 起执行并**逐集继承**。
